# EmotionAI - Face Emotion Detection

BCA final-year Computer Vision website with real-time webcam detection and image analysis.

## Features
- Dashboard
- Live webcam face detection
- Seven facial-expression classes: Happy, Sad, Angry, Fearful, Disgusted, Surprised, Neutral
- Confidence scores
- Multiple-face detection
- Image upload analysis
- Camera capture
- Local detection history and statistics
- Dark mode
- Responsive UI
- Project documentation

## Technology
HTML5, CSS3, JavaScript, WebRTC and face-api.js.

## Run
Use VS Code Live Server or `python -m http.server 5500`, then open `http://localhost:5500`.
Camera access works best on localhost or HTTPS. The AI model is loaded from the internet.

## GitHub Pages
Upload the four project files to your repository root and enable Pages from the main branch.

## Important
Expression recognition estimates visible facial expression. It should not be treated as a reliable measurement of a person's internal emotional state or used for high-stakes decisions.
